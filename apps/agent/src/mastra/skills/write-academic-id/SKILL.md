The output is Indonesian academic prose; these instructions are in English.

## Register
Write in formal Indonesian academic register. Avoid spoken forms and non-standard abbreviations. Use standard (baku) KBBI terminology; italicize foreign loanwords that are not yet absorbed. Keep sentences efficient — one main idea per paragraph.

## Argument structure
Follow the pattern: claim → supporting evidence/citation → interpretation → link back to the larger argument. Keep claim boundaries explicit; separate findings from opinion.

## Citation discipline
Every empirical claim must be sourced. Mark passages that need a reference as `[perlu sumber]`. Never fabricate researcher names or numbers.
