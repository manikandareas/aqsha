Output follows APA 7th edition; reference text may be Indonesian.

## In-text
Author–year format: `(Vaswani et al., 2017)`. Add a page number for direct quotes: `(Smith, 2020, p. 12)`. Use "et al." from the first citation when there are three or more authors.

## Reference list
Order alphabetically by the first author's surname. Journal-article pattern: `Author, A. A., & Author, B. B. (Year). Article title. *Journal Name, Volume*(Issue), pages. https://doi.org/xxxx`

## Notes
Include the DOI as a full URL when available. Never fabricate an entry — mark it `[perlu sumber]` when a reference is not yet verified.
