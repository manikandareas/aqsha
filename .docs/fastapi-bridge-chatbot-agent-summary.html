FastAPI Bridge Chatbot Agent

Ringkasan implementasi yang sudah dikerjakan untuk menjadikan apps/agents sebagai internal FastAPI runtime dan apps/api sebagai public gateway, persistence owner, dan SSE proxy untuk chatbot agent.

Repo: aqsha-agent-fastapi Tanggal: 2026-04-26 Scope: apps/agents + apps/api + packages/db

Hasil Utama

Implementasi sekarang memisahkan runtime agent dan public API secara eksplisit. apps/agents menjalankan DeepResearchFlow melalui FastAPI internal, sementara apps/api tetap menjadi entrypoint untuk web, mengelola auth, workspace ownership, Postgres persistence, concurrency, dan SSE publik.

V1 tidak menambahkan token-by-token streaming. Prioritas yang diterapkan adalah event-rich progress timeline yang dipersist dan bisa direplay dari PostgreSQL.

Perubahan di apps/agents

  • Menambahkan FastAPI adapter di apps/agents/src/deep_research_agent/api/.
  • Menambahkan endpoint internal GET /health dan POST /v1/chat/stream.
  • Menambahkan schema request ChatStreamRequest yang menerima runId, threadId, workspaceId, userId, message, depthMode, dan messageHistory.
  • Menambahkan EventFactory untuk membentuk event SSE internal dengan sequence yang stabil.
  • Menambahkan optional bearer token guard melalui AGENTS_API_TOKEN.
  • Menambahkan dependency Python: fastapi, uvicorn, pydantic-settings, dan pytest.

DeepResearchFlow Event Sink

DeepResearchFlow direfactor ringan agar bisa menerima optional event_sink. Flow sekarang mengirim lifecycle event tanpa mengubah contract CLI lama.

Casual Chat

  • router.started
  • router.completed
  • assistant.message.completed
  • run.completed

Research

  • planning.started / planning.completed
  • evidence.iteration.started
  • evidence.search.started / completed
  • evidence.review.completed
  • synthesis.started / completed
  • citation_audit.started / completed

Perubahan di apps/api

Menambahkan module baru apps/api/src/modules/agents/ mengikuti pola repo: index.ts, model.ts, service.ts, dan repository.ts.

  • POST /agents/threads membuat thread baru.
  • GET /agents/threads mengambil daftar thread aktif.
  • GET /agents/threads/:threadId mengambil detail thread, messages, latest run, dan events.
  • POST /agents/threads/:threadId/messages membuat user message + run lalu membuka SSE stream ke web.
  • GET /agents/runs/:runId/events replay event timeline yang sudah dipersist.
  • POST /agents/runs/:runId/cancel menandai run sebagai cancel_requested untuk V1.

Persistence Model

packages/db/src/schema.ts sekarang memiliki table baru untuk state chatbot agent. Migration dibuat di apps/api/drizzle/0007_agent_chat_threads.sql.

agent_threads

Thread milik workspace/user, title, depth mode, status, timestamps.

agent_messages

Chat history canonical: user, assistant, dan system messages.

agent_runs

Status eksekusi run: queued, running, completed, failed, cancel_requested.

agent_events

Timeline event per run dengan sequence, type, status, title, payload, visibility.

Concurrency dan SSE

  • Satu active run per thread diterapkan melalui query check dan unique index partial pada agent_runs.
  • Jika thread masih memiliki run queued atau running, API mengembalikan 409 agent_session_busy.
  • apps/api memanggil internal apps/agents /v1/chat/stream, mempersist event yang diterima, lalu meneruskan SSE ke web.
  • assistant.message.completed dipakai sebagai sinyal untuk menyimpan assistant message ke PostgreSQL.

Environment

  • apps/api/src/config.ts menambahkan AGENTS_API_URL default http://localhost:8000.
  • AGENTS_API_TOKEN bersifat optional untuk internal bearer token antara API dan FastAPI service.
  • apps/api/.env.example diperbarui agar env baru terlihat untuk local setup.

Testing dan Verifikasi

Command yang sudah dijalankan dan berhasil:

  • cd apps/agents && uv run pytest
  • bun run --filter @aqsha/api typecheck
  • bun run --filter @aqsha/db typecheck
  • bun run --filter @aqsha/api lint

Sebelum verifikasi TypeScript, bun install dijalankan karena tsc belum tersedia di workspace. Setelah itu scoped checks berhasil.
